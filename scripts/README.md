# Скрипты

## Проверка адаптива (`shot.mjs`, `shot-all.mjs`)

Скриншоты страниц в нескольких ширинах на Playwright. Кроме самих снимков
скрипт ищет **горизонтальное переполнение** и называет элемент, который его
вызывает, — это самая частая поломка адаптива, и по сборке её не видно.

Правило простое: после любых правок вёрстки прогнать и **посмотреть картинки**,
а не только строку «переполнения нет» в выводе.

### Запуск

```bash
npm run dev            # в одном терминале
npm run shot -- /      # в другом
```

Примеры:

```bash
npm run shot -- / --full                       # вся страница, все ширины
npm run shot -- /exchange --w=375,1440         # только эти ширины
npm run shot:all                               # регресс по ключевым страницам
npm run shot:all -- /ratings /credit-cards     # свой набор страниц
npm run shot -- / --base=https://moneyswap.online   # снять прод для сравнения
```

Порт по умолчанию 3000. Другой — через `SITE_URL=http://localhost:3001`.

### Меню и другие интерактивные элементы

На обычном скриншоте выпадающего меню не видно — его надо открыть:

```bash
# десктопная мега-панель «Сервисы»
npm run shot -- / --w=1440 --hover='a:has-text("Сервисы")' --suffix=menu

# мобильное меню: открыть бургер и раскрыть аккордеон (клики разделяются «;»)
npm run shot -- / --w=375 --suffix=menu \
  --click='.lucide-menu; [role="dialog"] button:has-text("Сервисы")'
```

### Флаги

| Флаг | Что делает |
|---|---|
| `--w=375,1440` | список ширин (по умолчанию 375, 576, 768, 1024, 1440, 1920) |
| `--full` | снимок всей страницы, а не первого экрана |
| `--hover='селектор'` | навести курсор перед съёмкой |
| `--click='a; b'` | кликнуть по очереди, разделитель `;` |
| `--wait='селектор'` | дождаться элемента |
| `--suffix=menu` | суффикс в имени файла, чтобы не затирать основной снимок |
| `--base=URL` | другой хост |

### Что учтено внутри

- на ширинах ≤768 включается эмуляция тача: в `tailwind.config.ts` стоит
  `hoverOnlyWhenSupported`, и hover-стили там срабатывать не должны;
- страница прокручивается до конца, иначе блоки с появлением по
  `IntersectionObserver` останутся прозрачными;
- высота окна для мобильных берётся как у реальных устройств, а не пропорцией.

**Ограничение:** `--full` несовместим с открытым мобильным меню — drawer
позиционирован фиксированно, и на полностраничном снимке попадёт только его
верхняя часть. Для меню снимайте без `--full`.

Файлы складываются в `scripts/data/shots/<страница>/<ширина>[-суффикс].png`
и не попадают в репозиторий.
